📸 Shadow Map Calculation:

问题 (Question): Shadow map 是怎么计算的？
回答 (Answer): 是的！从光源方向计算！

两遍渲染 (Two-Pass Rendering):
1️⃣ 从光源视角渲染场景深度 → Shadow Map
2️⃣ 从相机视角渲染，采样Shadow Map判断阴影

Yes! Calculated from light direction!
Pass 1: Render depth from light's perspective → Shadow Map
Pass 2: Render from camera, sample Shadow Map for shadows

详细说明请查看: SHADOW_MAP_CALCULATION.md

🔄 Shadow Map Updates:

问题 (Question): 光源方向改变时会重新计算shadowmap吗？
回答 (Answer): 是的！每一帧都重新计算！

更新频率 (Update Frequency):
⚡ 每帧自动更新（通常 60 FPS）
✅ 光照方向改变 → 立即生效
✅ 物体移动 → 阴影自动跟随
✅ 无需手动触发更新

Yes! Recalculated every frame!
Shadow map updates automatically at ~60 FPS. Light direction changes take effect immediately.

详细说明请查看: SHADOW_MAP_UPDATE.md

⚙️ Shadow Bias Control:

问题 (Problem): Splat 被错误遮挡？
解决 (Solution): 调整 Shadow Bias！

Shadow Bias 作用:
🔹 太小 → 自阴影问题 (shadow acne)
🔹 太大 → 阴影分离 (Peter Panning)
🔹 合适 → 正确的阴影！✨

调整方法:
在 GUI 中调整 "Shadow Bias" 滑块 (0.0001 - 0.01)
默认值: 0.002（已优化）

If splats show incorrect shadows:
Adjust "Shadow Bias" in GUI. Higher values reduce false shadows.
